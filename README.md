# Inventaris-app

Dit wordt een web app voor een schrijnwerker waar hij uren, materiaal, offertes,... mee kan op maken

- Werkregels: [`CLAUDE.md`](CLAUDE.md)
- Plan en datamodel: [`docs/PLAN.md`](docs/PLAN.md)
- Open vragen: [`docs/VRAGEN.md`](docs/VRAGEN.md)

## Lokaal draaien

1. Node 22 installeren
2. `npm install`
3. `.env.example` kopiëren naar `.env.local` en invullen
4. `npm run dev` en open http://localhost:3000

Vóór elke commit: `npm run check`.
